# mestami-vkusno-design-scaffold

Каркас дизайна «Местами вкусно»: дизайн-система и проработанный прототип интерфейса (каркас фронтенда).

## Статус
Репозиторий только создан. Стек и структура пока не выбраны.

## Что есть
- `design-system.html` — одностраничная витрина дизайн-системы без контекста приложения: цвета, типографика, отступы и скругления, кнопки, поля, чипы, бейджи, карточки, навигация, иконки. Токены — в блоке `:root` в начале файла. Есть тёмная (основная) и светлая тема, переключатель вверху страницы; тема задаётся атрибутом `data-theme` на `<html>` или на любом блоке. Страница адаптирована под телефоны (проверено на 390 px): панель разделов прокручивается, сетки перестраиваются, на сенсорных экранах увеличены зоны нажатия. Открывается двойным кликом, сборка не нужна.

## Источник истины
Функции и поведение определяют документы в репозитории-рабочей области
[mestami-vkusno-workspace](https://github.com/mestami-vkusno/mestami-vkusno-workspace): ТЗ и юридический пакет в `materials/`.
Дизайн-референсы (`materials/design/` там же) служат только для сборки дизайн-системы: стиль, палитра, компоненты.
При расхождении дизайна и ТЗ побеждает ТЗ.

## Связанные репозитории
- `mestami-vkusno-prototype` — временный прототип на Vue. Не финальная версия, не использовать как основу.
