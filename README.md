# mestami-vkusno-frontend

Каркас фронтенда «Местами вкусно»: проработанный прототип интерфейса и дизайн-система.

## Статус
Репозиторий только создан. Стек и структура пока не выбраны.

## Источник истины
Функции и поведение определяют документы в репозитории-рабочей области
[mestami-vkusno-workspace](https://github.com/mestami-vkusno/mestami-vkusno-workspace): ТЗ и юридический пакет в `materials/`.
Дизайн-референсы (`materials/design/` там же) служат только для сборки дизайн-системы: стиль, палитра, компоненты.
При расхождении дизайна и ТЗ побеждает ТЗ.

## Связанные репозитории
- `mestami-vkusno-prototype` — временный прототип на Vue. Не финальная версия, не использовать как основу.
